# Address Book System App

## Overview
Spring Boot REST application to manage Address Book contacts.
Developed following strict Gitflow branching, with multi-line class comments and single-line method comments.

## Tech Stack
- Java 17, Spring Boot 3.2.3, Lombok, Validation API

## Branching Strategy
- `main`: Contains only README.md.
- `develop`: Main integration branch for all features.
- Feature branches merged sequentially.
